# Customer Intelligence Studio

An interactive R + Shiny academic project for e-commerce customer analytics.

## Features
- Premium Shiny dashboard using bslib
- KPI overview and revenue trend
- RFM customer segmentation
- Customer DNA radar view
- Customer personality classification
- K-Means clustering with silhouette-based K selection
- Cohort retention heatmap
- Product explorer
- Country/revenue intelligence
- Rule-based Smart Insights
- What-if Campaign Simulator
- Searchable customer data and CSV download

## Run locally
1. Open the project folder in RStudio.
2. Run `source("packages.R")`.
3. Run `shiny::runApp("app")`.

The app expects `data/OnlineRetail.csv`.
